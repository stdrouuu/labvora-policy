Privacy Policy

Important Notice Educational Purpose

The Labvōra application was developed by Labvora Informatics Engineering as an academic project for learning and demonstration purposes. All data contained in the application, including names, addresses, phone numbers, emails, schedules, and transaction history, is fictitious (dummy) data for simulation and testing. This application does not process real transactions or connect to any official service systems.

Labvōra was developed by Labvora Informatics Engineering. This policy explains that registration data (name, phone number, address, email, password) you enter is treated as fictitious (dummy) project data, stored in the project database to simulate application functions, and never shared with third parties.

1. Introduction and Educational Purpose

Welcome to Labvōra. This application was built as a student project to demonstrate Android development (registration, scheduling, and reservations). All data inside user accounts, profiles, schedules is fictitious (dummy) data for demo and testing, not real data. We do not request or require your genuine personal data to use the application.

2. Fictitious (dummy) Data Collected

To simulate registration and booking functions, the application allows you to enter the following data. All of it is treated as fictitious project data and stored in the project database to demonstrate how the application works:

  • Full Name, Phone Number, Full Address, Email, and Password (from the Registration Form) fictitious (dummy), for account simulation.
  • Account and activity data: demo credentials, reservation history / simulated schedules you create in the application.
  • No collection of real time location, contacts, personal photos, or other sensitive data beyond what you type as dummy.

2.1. Identity and Personal Data (Dummy)

The Full Name, Phone Number, Full Address, and Email fields in the registration form are for demo only. Please use fictitious data only. Data you enter is stored in the project database as part of the simulation and is not used for any other purpose outside this project demo.

2.2. Account and Activity Data (Dummy)

Demo passwords, session tokens, and simulated reservation / schedule history are stored in the project database to demonstrate login, booking, and history functions. All of it is simulation data and does not process real transactions.

3. Purposes of Fictitious (dummy) Data Use

Fictitious (dummy) data is used only for:

  • Demonstrating simulated account registration and login.
  • Demonstrating creation, storage, and display of demo schedules / reservations.
  • Testing and evaluation of the educational project. Not for advertising, commercial analytics, or real services.

4. Data Storage and Security

Fictitious (dummy) data is stored in the project backend database for simulation. We apply restricted access for project purposes. Because this is an educational project, do not enter real personal data data that has already been entered can be deleted by deleting your account / application data or contacting us. Uninstalling or clearing application data will delete local data on your device.

5. No Data Shared with Third Parties

Fictitious (dummy) project data is never shared, sold, or rented to any other company or organization for advertising or commercial purposes. Data is only used within the scope of this application demo.

6. User Rights and Account Deletion Policy

Control over your demo account and fictitious (dummy) data is our priority. You can delete your account and demo data at any time:

6.1. How to Delete Your Account in the App

You can permanently delete your account directly through the Profile menu in the Labvōra application by following these steps:

  1. Open the Labvōra application and sign in to your account.
  2. Go to the Profile menu.
  3. Scroll down and tap the DELETE ACCOUNT button.
  4. Tap Continue on the first warning dialog.
  5. Tap Yes, Delete Account on the final confirmation dialog.

6.2. Data That Will Be Deleted

Your demo name, phone number, address, email, password, and simulated schedule / reservation history will be deleted from the project database and cannot be restored.

6.3. Temporary Storage and Retention

Fictitious (dummy) data is only stored for the duration of the demo project and is not used for commercial purposes. There is no long term retention beyond demonstration needs.

6.4. Confirmation and Support

For questions or data deletion requests, contact the developer Labvora Informatics Engineering via email at brandon.412024022@civitas.ukrida.ac.id.

7. Policy Acceptance and Changes

By registering with fictitious (dummy) data and using the application, you agree to this Privacy Policy. This application is purely an educational simulation it does not process real transactions or connect to real service systems. If the project scope changes, this policy will be updated.
